# 🧮 botyaracalc

Modern desktop calculator on PyQt5.

## Features

- **Expression engine** with input validation & sanitization, typed results (`CalcResult`) with error handling
- Functions: `sqrt`, `%`, negate; **memory**: M+, M−, MR, MC
- **History panel**
- **Scientific mode** toggle
- **Light / dark** themes
- **RU/EN** interface with language dialog
- Sounds, font size and precision settings — persisted in `calculator_config.json`

## Run

```bash
pip install PyQt5
python main.py
```
